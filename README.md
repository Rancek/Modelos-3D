# 🗿 Esculpido digital

El **esculpido digital** fue otra de las áreas trabajadas durante el desarrollo de mis proyectos 3D.

Esta etapa permite trabajar las formas de una manera más orgánica y desarrollar detalles que posteriormente pueden incorporarse al modelo final.

Durante este proceso trabajé principalmente:

- 🗿 Formas principales.
- 🧍 Anatomía.
- 👤 Rasgos de personajes.
- 🔍 Detalles secundarios.
- ✨ Detalles de superficie.
- 📐 Proporciones y silueta.

**Formas básicas → Volumen → Proporciones → Detalles → Refinamiento**

---

# 🕸️ Topología y construcción 3D

La topología es una parte importante dentro del desarrollo de un modelo tridimensional.

Durante mis estudios fui aprendiendo a organizar la geometría buscando mantener una estructura adecuada para continuar trabajando posteriormente con el modelo.

Algunos de los aspectos considerados fueron:

- 🔲 Distribución de polígonos.
- 🔄 Flujo de geometría.
- 🧩 Organización de la malla.
- 📐 Conservación de las formas.
- 🎭 Preparación de personajes.
- 🎬 Preparación para animación.

---

# 🎨 Texturizado y materiales

Una vez desarrollado el modelo, el trabajo de texturizado permite agregar información visual a las superficies y mejorar la presentación del objeto o personaje.

Durante esta etapa trabajé diferentes aspectos como:

- 🎨 Color.
- 🧱 Materiales.
- 🔍 Detalles de superficie.
- ✨ Variaciones visuales.
- 🖌️ Pintura de texturas.
- 🧊 Apariencia final del modelo.

**Modelo → UV → Texturas → Materiales → Iluminación → Render**

---

# 💡 Iluminación y presentación

La presentación final también forma parte del proceso de creación de un modelo 3D.

La iluminación permite destacar las formas, materiales y detalles desarrollados durante el proyecto.

En esta etapa trabajé principalmente:

- 💡 Posicionamiento de luces.
- 🌑 Luces y sombras.
- 🎨 Presentación de materiales.
- 📷 Composición de cámara.
- 🖼️ Render final.

---

# ⚙️ Proceso de trabajo

### 🧊 Modelado

**Referencia → Formas básicas → Modelado → Detalles → Refinamiento**

### 🗿 Esculpido

**Referencia → Base → Volumen → Anatomía → Detalles → Escultura final**

### 🎨 Texturizado

**Modelo → UV → Materiales → Texturas → Ajustes**

### 🖼️ Presentación

**Modelo final → Materiales → Iluminación → Cámara → Render**
